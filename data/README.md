# Dataset: student_performance.csv

This is a **synthetic** dataset of 600 student records, generated by
`generate_dataset.py`, designed to mimic realistic academic performance
patterns for demonstration and educational purposes.

## Columns

| Column | Type | Description |
|---|---|---|
| `Student_ID` | string | Unique student identifier (e.g. `STU0001`) |
| `Age` | integer | Student age (17–24) |
| `Gender` | categorical | `Male` / `Female` |
| `Study_Hours` | numeric | Average weekly study hours |
| `Attendance` | numeric | Class attendance percentage (0–100) |
| `Assignments_Score` | numeric | Average assignment score (0–100) |
| `Midterm_Score` | numeric | Midterm exam score (0–100) |
| `Previous_Score` | numeric | Prior semester / baseline academic score (0–100) |
| `Sleep_Hours` | numeric | Average nightly sleep hours |
| `Internet_Access` | categorical | `Yes` / `No` |
| `Extracurricular_Activities` | categorical | `Yes` / `No` |
| `Final_Score` | numeric | Target variable — final academic score (0–100) |

## How relationships were built into the data

`Final_Score` is generated as a weighted combination of the other
features rather than pure random noise, so trained models can learn a
genuine signal:

- **Previous_Score, Midterm_Score, Assignments_Score, Attendance** each
  contribute ~20% weight to the final score.
- **Study_Hours** contributes a smaller but positive weight.
- **Internet_Access = Yes** and **Extracurricular_Activities = Yes**
  provide small positive boosts.
- **Sleep_Hours** has a mild penalty the further it deviates from ~7.5
  hours (too little or too much sleep is modeled as slightly detrimental).
- Random Gaussian noise is added on top to keep the data realistic and
  avoid a perfectly deterministic relationship.

`Attendance`, `Sleep_Hours`, and `Assignments_Score` also have a small
percentage of missing values, and a handful of duplicate rows were
intentionally injected, so the app's data cleaning and preprocessing
features have something real to demonstrate.

## Derived target: At_Risk

The app derives a binary classification target at runtime:

```
At_Risk = "At Risk"      if Final_Score < 50
At_Risk = "Not At Risk"  if Final_Score >= 50
```

## Regenerating the dataset

```bash
python generate_dataset.py
```

This overwrites `data/student_performance.csv` with a freshly generated
(but reproducible, via a fixed random seed) dataset.
